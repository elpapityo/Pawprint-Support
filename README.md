# Pawprint Support v0.1.0

Pawprintの「闘獣練を自動攻略」が途中でOFFになる箇所を監視し、必要に応じてONへ戻すための補助プラグインです。

> **重要**  
> Pawprint SupportはPawprint本体の自動攻略を置き換えるものではありません。

## 初回設定

1. **Pawprintボタン範囲を登録**  
   設定タブの「枠編集」を使い、「闘獣練を自動攻略」ボタンの判定範囲を合わせます。
2. **OFF画像を登録**  
   PawprintをOFF（白文字）にして登録します。
3. **ON画像を登録**  
   PawprintをON（グレー文字）にして登録します。
4. **判定テスト**  
   OFF / ONを正しく判定できるか確認します。
5. **停止キーを設定**  
   必要に応じて停止キーを登録します。初期値は `Ctrl + Esc` です。

## 動作手順

1. Pawprintの「闘獣盤」を開きます。
2. 「闘獣練を自動攻略」ボタンを押したときに動作する位置へPawprintを配置します。
3. 「闘獣練を自動攻略」ボタンが、ほかのウィンドウに隠れていない状態にします。
4. Pawprint Supportの「メイン」タブを開きます。
5. 「自動実行」にチェックを入れます。

## 注意事項

- Pawprint側の指定回数を「1回」にしていても、Pawprint Supportが自動攻略を再びONに戻すため、指定回数による停止はできません。
- 停止する場合はPawprint Supportの「自動実行」をOFFにするか、設定した停止キーを使用してください。
- 「ひきつけろ」補助は、ご使用の戦闘系プラグインなどで「ひきつけろ」が使えない場合に利用してください。
- FF14が非フォーカス時は背面クリックを試し、必要な場合だけ一時的にFF14へフォーカスして操作後に元へ戻します。
- FF14が最小化されている間は監視を待機します。
